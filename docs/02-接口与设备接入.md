# 接口与设备接入

## MQTT 认证

- Broker：`mqtt://CONTROL-01:1883`
- 用户名：`relay`
- 密码：`.env` 中的 `DEVICE_TOKEN`
- 状态/指标建议 QoS 0，控制/回执使用 QoS 1。

## 主题

| 主题 | 方向 | 内容 |
|---|---|---|
| `relay/{node_id}/status` | 设备 → 平台 | 角色、序号、模式、上下游、传感器和最后时间 |
| `relay/{node_id}/metric` | 探测端 → 平台 | 路径、窗口、收发/超时/重复、RTT、有效字节和转发数 |
| `relay/{node_id}/command` | 平台 → 设备 | 唯一命令号、目标、动作、发送时间 |
| `relay/{node_id}/ack` | 设备 → 平台 | 命令号、执行成功与错误原因 |
| `relay/{node_id}/alarm` | 设备 → 平台 | 告警是否有效和说明 |
| `relay/system/mode` | 平台 → 设备 | 人工选择的 `direct` 或 `relay` |

## 图像上传

```http
POST /api/device/TERM-01/frame
Content-Type: image/jpeg
x-device-token: <DEVICE_TOKEN>
x-frame-rate: 1
x-frame-width: 960
x-frame-height: 540
```

请求体为原始 JPEG/PNG，限制 3 MiB。服务保存每台设备的最新一帧，不做无界缓存。

## HTTP 控制接口

- `GET /api/health`：服务健康。
- `GET /api/snapshot`：完整实时快照。
- `POST /api/mode`：`{"mode":"direct|relay"}`。
- `POST /api/commands`：`{"target":"TERM-01","action":"lamp_on|lamp_off|alarm_reset"}`。
- `POST /api/demo/scenario`：仅演示模式可用。
