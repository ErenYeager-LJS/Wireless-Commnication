# 网络拓扑与首日冻结

## 主方案：双无线/双网段 TCP 应用层中继

```text
TERM-01 (192.168.60.20)
  │ Wi-Fi 下游网段 192.168.60.0/24
  ▼
RELAY-01 下游 192.168.60.1 / 上游 192.168.50.20
  │ relay-agent TCP 双向转发，带包/字节计数
  ▼
CONTROL-01 (192.168.50.10:1883 / :8787)
```

直连测试时 TERM-01 连接 `mqtt://192.168.50.10:1883`；中继测试时连接 `mqtt://192.168.60.1:1883`。两种模式必须使用同一终端、同一负载、同一测试位置。中继模式关闭 `relay-agent` 后业务必须中断，借此排除备用路径绕行。

## 冻结项

| 项目 | 当前决定 | 现场确认 |
|---|---|---|
| 转发方式 | TCP 应用层双向代理 | 检查关闭代理后业务确实中断 |
| 控制端 | Windows + Node.js 24 | 已具备 |
| 控制网段 | 192.168.50.0/24 | 按现场冲突情况调整 |
| 终端网段 | 192.168.60.0/24 | 按现场冲突情况调整 |
| MQTT | 本地 1883，用户名 `relay` | 必须修改默认令牌 |
| 网页 | 本地 8787 | 防火墙放行专用网络 |
| 状态周期 | 1 秒 | 已实现 |
| 离线阈值 | 5 秒 | `.env` 可配置 |
| 退化阈值 | P95 RTT ≥120ms 或丢包 ≥5% | `.env` 可配置 |
| 图像保底 | JPEG 1 FPS，建议 960×540 | 现场冻结摄像头能力 |
| 探测负载 | 128 字节，10 包/秒，60 秒 | 需接入硬件后采集原始日志 |

## 切换边界

大屏按钮会记录并广播人工选择的模式；真实终端必须同时把其 `mode`、`upstream` 和探测 `path` 上报回来。只有三者一致时路径才可作为验收证据。网络完全断开时，网页无法通过失效链路命令终端切换；现场必须保留终端本地配置/按钮或先恢复可达链路，这是网络系统的客观限制。
