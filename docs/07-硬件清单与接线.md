# 硬件清单与接线

## 当前事实

目前已知你有 1 块 ESP32，但尚未确认具体型号。以下先按最常见的 `ESP32 DevKit V1 / ESP32-WROOM-32` 配置。请以板子丝印为准；如果是 `ESP32-CAM`、`ESP32-S3` 或其他型号，引脚和摄像头方案必须调整。

## 建议采购清单

| 硬件 | 数量 | 建议型号/规格 | 用途 | 是否必须 |
|---|---:|---|---|---|
| 现有 ESP32 | 1 | 暂按 ESP32 DevKit V1 | 业务数据、按钮、灯控、链路探测 | 已有 |
| OpenWrt 小路由 | 1 | GL.iNet GL-MT3000 或同类双频 OpenWrt | 独立中继节点，2.4G 下游 AP + 5G/网线上游 | 必须 |
| DHT22 模块 | 1 | 带上拉电阻的三针模块 | 真实温湿度上报 | 必须 |
| 瞬时按钮 | 1 | 常开按钮 | 实体告警与长按切换 | 必须 |
| 普通 LED | 1 | 5 mm 红色 LED | 开发调试灯控 | 必须 |
| 电阻 | 1 | 220 Ω，1/4W | LED 限流 | 必须 |
| 警示灯 | 1 | 5V USB LED 警示灯 | 成品实体效果 | 成品建议 |
| MOSFET 驱动 | 1 | 3.3V 逻辑电平 MOSFET 模块 | ESP32 安全控制 5V 灯 | 使用警示灯时必须 |
| 面包板/杜邦线 | 1 套 | 公对公、公对母 | 原型接线 | 必须 |
| USB 电源 | 2 | 5V 2A | ESP32 与路由器供电 | 必须 |
| 摄像终端 | 1 | AI Thinker ESP32-CAM（OV2640）+ USB-TTL 下载器 | 远端现场图像 | 图像验收必须 |

不建议用第二块普通 ESP32 代替 OpenWrt 路由器做正式中继。ESP32 单无线电 NAT/转发带宽、同信道竞争和可观测性较差，难以稳定达到图像并发时的验收指标。

### 按现有板型购买

- 如果现有板是普通 `ESP32 DevKit V1/WROOM-32`：保留它做业务终端，购买 1 块 AI Thinker ESP32-CAM、1 个 USB-TTL 下载器和 1 台 GL-MT3000。
- 如果现有板是 `AI Thinker ESP32-CAM`：它负责图像；另购 1 块 ESP32 DevKit V1 负责按钮、DHT22 和灯控，再购买 1 台 GL-MT3000。
- 如果现有板是带摄像头的 `ESP32-S3`：有机会合并为一个终端，但必须先确认具体板型和摄像头引脚，再决定是否免购 ESP32-CAM。

建议正式清单采用：`GL.iNet GL-MT3000`、`AI Thinker ESP32-CAM + OV2640`、`ESP32 DevKit V1`、`DHT22 三针模块`、`5V USB 红色警示灯`、`3.3V 逻辑 MOSFET 开关模块`、`常开按钮`、`220Ω 电阻`、`5V 2A USB 电源 ×2`。这套组合与现有代码一一对应。

## ESP32 DevKit 接线

| 模块 | ESP32 | 说明 |
|---|---|---|
| DHT22 VCC | 3V3 | 不使用 5V 数据电平 |
| DHT22 DATA | GPIO25 | 三针模块通常自带上拉 |
| DHT22 GND | GND | 共地 |
| 告警按钮一端 | GPIO27 | 程序启用内部上拉 |
| 告警按钮另一端 | GND | 短按告警，长按切换路径 |
| 红 LED 正极 | GPIO26 经 220Ω | 调试警示灯 |
| 红 LED 负极 | GND |  |
| MOSFET IN | GPIO26 | 使用成品 5V 灯时替代普通 LED |
| MOSFET GND | GND | 必须共地 |

## 需要你确认的唯一硬件信息

拍摄 ESP32 正面、背面和 USB 接口附近丝印，或直接提供完整型号。确认后才能锁定摄像头、可用 GPIO、供电和最终外壳尺寸；在此之前不能负责任地声称硬件成品已经完成。

## 固件入口

- `编译ESP32固件.cmd`：在项目内构建普通终端和摄像头固件。
- `烧录现有ESP32终端.cmd`：自动检测唯一串口并烧录普通 ESP32。
- `烧录ESP32摄像头.cmd`：烧录 AI Thinker ESP32-CAM；下载模式需要 GPIO0 接地。
- 已编译镜像位于 `firmware/builds/`。镜像中的 Wi-Fi 和令牌目前是安全占位值，必须先编辑各工程的 `include/secrets.h` 并重新编译，不能直接用于现场。
