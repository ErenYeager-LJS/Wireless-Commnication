# 三分钟演示脚本

| 时间 | 操作 | 讲解重点 |
|---|---|---|
| 0:00–0:25 | 展示园区全景，点击楼层抽出 | 地下设备走廊、终端、中继和控制端位置 |
| 0:25–0:50 | 点选 TERM-01，触发实体告警按钮 | 画面、温湿度、告警和最后时间来自现场设备 |
| 0:50–1:20 | 人工选择直连，展示退化/失联 | 指出人工选择；读取丢包、P95 和测试轮次 |
| 1:20–1:55 | 人工启用中继 | 路径以实际上游、探测包和转发计数为证据点亮 |
| 1:55–2:25 | 对比两种路径 | 强调同位置、同设备、同负载和 60 秒窗口 |
| 2:25–2:45 | 点击点亮警示灯 | 观察实体灯动作，再展示相同命令号的执行回执 |
| 2:45–3:00 | 恢复园区全景 | 总结恢复时间、闭环与本地离线运行 |

演示前运行三轮彩排。真实验收时隐藏演示注入区（以 `real` 模式启动），禁止将受控断链表述为自然遮挡收益。
